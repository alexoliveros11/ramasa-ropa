# RAMASA ROPA - CRUD de Productos en Django

## Descripción
Aplicación web para gestionar productos de una tienda de ropa. Permite crear, ver, editar y eliminar productos desde la interfaz web y también desde una API REST.

## Tecnologías
- Django 4.2.1
- Django REST Framework 3.14.0
- Bootstrap 5
- SQLite
- Postman (para pruebas de API)
